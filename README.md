# Diabolic Pixel Dungeon (web build)

Playable build of Diabolic Pixel Dungeon, a gothic-horror action-RPG on the Pixel Dungeon engine
(GPL-3.0; derived from Eternity / Shattered Pixel Dungeon). This repository only contains build
output; it is published with GitHub Pages.

Play: https://stew15.github.io/diabolic-pd-web/ — on iPhone, use Share → Add to Home Screen.
